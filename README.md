# lizzard AI Usage

Consulte o uso das suas ferramentas de IA direto na barra de status do VS Code. O indicador mostra o percentual usado e o tempo até a renovação dos limites. A atualização automática ocorre a cada 10 minutos.

Clique nos dados para atualizar na hora. Use a engrenagem para escolher uma fonte e ajustar as configurações. Se nenhuma fonte estiver selecionada, clique em **selecione fonte**.

## Fontes disponíveis

- **Codex** — uso percentual nas janelas de 5 horas e semanal. Requer a extensão oficial do Codex autenticada ou um caminho configurado para o Codex CLI.
- **Claude Code** — uso percentual nas janelas de 5 horas e 7 dias. Configure pelo menu da engrenagem; os dados aparecem depois que o Claude Code enviar os limites de uso.
- **GitHub Copilot** — créditos de IA consumidos em relação à franquia mensal, por exemplo `1234/3200 cr`. Configure um token do GitHub com permissão de leitura do plano e informe sua franquia mensal.

Passe o mouse sobre os dados para ver detalhes dos limites e da próxima renovação. O token do Copilot é guardado no armazenamento seguro do VS Code.
